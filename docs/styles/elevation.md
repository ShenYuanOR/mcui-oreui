# 阴影层级 / Elevation

`elevation-0–24` 使用 Ore UI 无模糊像素阴影。等级越高，向右下方的像素偏移越大；颜色由 `--mc-shadow` 控制。

## 基础用法

<div class="mc-demo mc-demo--column">
  <div class="mc-utility-demo__grid" style="gap:36px">
    <div class="mc-utility-demo__swatch elevation-0">elevation-0</div>
    <div class="mc-utility-demo__swatch elevation-2">elevation-2</div>
    <div class="mc-utility-demo__swatch elevation-4">elevation-4</div>
    <div class="mc-utility-demo__swatch elevation-8">elevation-8</div>
    <div class="mc-utility-demo__swatch elevation-12">elevation-12</div>
    <div class="mc-utility-demo__swatch elevation-16">elevation-16</div>
    <div class="mc-utility-demo__swatch elevation-20">elevation-20</div>
    <div class="mc-utility-demo__swatch elevation-24">elevation-24</div>
  </div>
</div>

```html
<section class="elevation-6">像素阴影表面</section>
```
