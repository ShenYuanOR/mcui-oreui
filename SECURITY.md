# Security Policy

## Supported versions

Security fixes are provided for the current npm `latest` release. Preview versions on the `next` tag receive fixes when they are promoted or superseded.

## Reporting a vulnerability

Please use GitHub's private security advisory flow for `ShenYuanOR/mcui-oreui`. Do not open a public issue containing exploit details, credentials, or private user data. Include affected versions, reproduction steps, impact, and any suggested mitigation. Maintainers will acknowledge a complete report within seven days.
